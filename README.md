# Пасьянс · Коллекция

Семь пасьянсов в собственном спокойном оформлении, полностью на русском языке. Отдельное офлайн-приложение для Windows 10/11 x64 и версия для браузера. Проект не связан с Microsoft и не использует её графику.

## Игры

- **Косынка**: выдача по одной или три карты, дома по мастям, перенос последовательностей, повторный проход колоды.
- **Паук**: одна, две или четыре масти; автоматический сбор полных серий; пять дополнительных раздач.
- **Свободная ячейка**: четыре временные ячейки, перенос серий с учётом реального количества свободных мест.
- **Пирамида**: пары с суммой 13, одиночные короли, резерв и два повторных прохода.
- **Три вершины**: соседние достоинства, переход король–туз, ограниченный резерв.
- **Юкон**: перенос произвольных открытых групп, дома по мастям, вся колода на столе.
- **Гольф**: семь столбцов, только верхние карты, соседние достоинства без перехода король–туз.

Общее: перетаскивание и выбор нажатием, до 150 отмен, подсказки допустимых ходов, отправка доступных карт в дома, повтор раздачи, пауза, таймер, очки и статистика. Три темы стола, девять рубашек, синтезированные звуки с отключением, поддержка уменьшенного движения. Семь ежедневных раздач обновляются по московскому времени; их разрешимость не гарантируется.

## Что нового в 1.1

- «Мой путь»: уровни игрока и мастерство по каждому из семи пасьянсов, 12 достижений с наградами.
- По три ежедневных и недельных цели. Сброс — по московской дате; неделя начинается в понедельник. Нет штрафов за пропущенные дни.
- Опыт за победу: 100 XP, за дуэль — 160, за этаж — 180. Игра без подсказок и отмен даёт +40 XP, победа быстрее пяти минут — +20 XP. Награды целей и достижений забираются вручную.
- Марафон: Гольф → Косынка → Три вершины, независимое сохранение, 60 монет за этап и бонус 180 монет / 250 XP за весь маршрут. «Косынка» в марафоне конструктивно разрешима; остальные этапы случайны, бесплатный новый вариант доступен.
- «Сад спокойствия»: «Три вершины» без отображения часов и счёта; награды и сохранения доступны.
- Решаемая «Косынка» использует проверяемый конструктивный генератор. Подсказка по-прежнему не является полным решателем произвольной позиции.
- Раздачи по номеру: числа 0–4 294 967 295; одинаковые номер и правила дают одинаковые карты. Нумерация собственная, не Microsoft.
- Новая графика наград imagegen; портреты фигур с сохранением квадратных пропорций, правильные схемы мастей, адаптивные угловые номиналы, плавное перемещение карт. Контрастные лица переключаются в настройках. Уменьшенное движение поддерживается.
- Управление свободными местами с клавиатуры, восстановление фокуса после выбора и диалогов, необязательная подсказка новичку.
- Сохранения 1.0 мигрируют: прежние партии, монеты, рубашки и результаты сохраняются. Уже оплаченные результаты не дают повторный опыт.

Обоснование решений и проверенные источники: [docs/design-research.md](docs/design-research.md). Сравнение ограничено доступными источниками, результаты удержания реальных игроков не измерялись.

## Дуэли, лига, магазин и башни

**Дуэль с ботом:** два настоящих стола «Косынки» и одна разрешимая раздача на двоих. Шесть характеров отличаются скоростью, длительными паузами и вероятностью неудачного хода с последующей отменой. Боты выбирают только разрешённые ходы по открытым картам; они не получают сведения о закрытых картах. Побеждает первый, кто соберёт все дома. Кнопка «В дома» в дуэли выполняет один ход за нажатие. Пауза, диалоги, скрытая вкладка и выход из режима останавливают обе стороны. Дуэль сохраняется отдельно от обычной «Косынки».

**Лига ботов:** явно вымышленный локальный рейтинг из 16 ботов и игрока. Показатели ботов детерминированно меняются в полночь по Москве; ваше место пересчитывается. Игрок получает +24 за победу в дуэли и −12 за поражение, минимум 400. Это не сетевые результаты реальных людей.

**Магазин:** стартовый подарок 240 монет, обычная победа +60, ежедневная +100, дуэль +120 за победу. Поражение после хотя бы 30 активных секунд и четырёх карт в домах приносит 15 утешительных монет. Повторная выплата за тот же результат блокируется. Шесть дополнительных рубашек стоят 120–650 монет; три базовые бесплатны. Реальных платежей нет. Баланс, покупки, матчи и башни входят в экспорт прогресса.

**Царь горы:** семь независимых башен, по семь этажей для каждого пасьянса. Вступление бесплатно. Победа открывает следующий этаж и приносит 75–225 монет. Хранители — оригинальное оформление одиночного испытания, а не онлайн-соперники. На следующих этажах уменьшаются лимиты подсказок (3 → 0), отмен (10 → 0) и времени. «Паук» растёт от одной до четырёх мастей; «Свободная ячейка» теряет до двух временных ячеек; «Косынка» переходит к трём картам и ограниченным проходам колоды; «Пирамида» — к резерву без повторов. У «Трёх вершин» ужесточаются время и помощь. Уровни случайны: разрешимость башенных раздач не гарантируется. Новая попытка и новый вариант этажа бесплатны. Пройденные этажи сохраняются; после всей башни можно начать новый подъём.

**Графика imagegen:** четыре оригинальных атласа в `src/assets/`: девять рубашек, четыре масти с прозрачностью восемь портретов хранителей и девять медальонов наград. CSS адресует участки атласов без изменения исходных изображений. У атласа рубашек фактические границы строк отличаются от идеальной сетки — координаты учтены в `src/assets.css`. Графика включена в офлайн-пакет Windows. Оригиналы генераций сохранены также в `/workspace/generated_images`.

## Windows

Распакуйте **весь** архив `Solitaire-Collection-RU-1.1.0-x64.zip` в отдельную папку. Запустите `Solitaire Collection RU.exe`. Установка и интернет не нужны. Не переносите один EXE без остальных файлов. Прогресс хранится в профиле пользователя Electron и остаётся при обновлении папки приложения. Перед переносом на другой компьютер экспортируйте прогресс в настройках.

Сборка не подписана цифровым сертификатом. Windows может показывать предупреждение SmartScreen. Нативный запуск Windows требует проверки на целевой системе: облачная разработка и браузерные тесты выполняются в Linux.

## Разработка

Node.js 24 и npm. Используйте существующий checkout; отдельный Git worktree не нужен.

```sh
npm ci
npm run dev -- --port 5174 --strictPort
```

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

Если Chromium установлен в `/usr/bin/chromium`, тесты используют его без скачивания. Для другого пути задайте `CHROMIUM_PATH`. Браузерные тесты запускают собранное приложение через `vite preview` на порту 5180. Они проверяют семь игр, переносы, отмену, победу, сохранение, задания дня, настройки, экспорт и импорт. Скриншоты сохраняются в `/workspace/artifacts` (вне облака — в `artifacts/`).

```sh
npm run desktop
npm run windows
```

Результат Windows-сборки — в `release/`. При ограниченном доступе к домашней папке в облаке:

```sh
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci --cache /workspace/.npm-cache --no-audit --no-fund
XDG_CACHE_HOME=/workspace/.cache ELECTRON_BUILDER_CACHE=/workspace/.cache/electron-builder npm run windows
```

Для `npm run desktop` нужен установленный бинарный Electron текущей ОС; не используйте `ELECTRON_SKIP_BINARY_DOWNLOAD` при обычной установке на Windows. Windows-сборка на Linux загружает официальный Windows runtime отдельно, с проверкой контрольных сумм. Используются `registry.npmjs.org`, `github.com` и `release-assets.githubusercontent.com`. Серверная часть, секреты и учётные записи не требуются.

## Прогресс и управление

Ходы сохраняются сразу, время — каждые пять секунд и при закрытии/сворачивании. Сохранение — локальное; удаление данных приложения удаляет прогресс. Экспорт/импорт JSON находится в настройках. Структура импорта проверяется, перед заменой запрашивается подтверждение. Повреждённое сохранение не исполняется как код.

`Ctrl+Z` — отмена, `H` (физическая клавиша, включая русскую раскладку) — подсказка, `Space` — колода, `Esc` — снять выбор/закрыть диалог. Двойное нажатие на карту отправляет её в подходящий дом. В «Пирамиде» и «Трёх вершинах» карты убираются нажатием. Подсказка показывает разрешённый ход, но не является решателем и не гарантирует победу. Кнопка «В дома» отправляет доступные карты без проверки стратегической безопасности; ходы можно отменить.

## Архитектура и проверки

- `src/engine.ts`: чистые правила семи игр, детерминированные раздачи, проверка ходов и подсказки.
- `src/storage.ts`: валидация сохранений, статистика, московская дата и seed дня.
- `src/main.ts`, `src/style.css`: интерфейс и управление.
- `electron/main.cjs`: изолированное окно приложения без Node.js в renderer, запрет внешней навигации.
- `src/*.test.ts`: 38 тестов правил, прогресса, миграции и соревнований, включая контроль сохранности карт.
- `scripts/*.spec.ts`: 49 сценариев в Chromium на production-сборке, включая новые режимы и проверку геометрии карт.
